Review all system recipes in `scripts/system-recipes.ts` and update that file directly. Work through them systematically.

## Method steps

- Split long method steps into shorter, clear steps. No recipe should have only one method step (e.g. Pork Schnitzel with Potato Salad).
- If steps or ingredients are missing, add them so the recipe is complete and cookable.

## Ingredients

- Any ingredient visible in the recipe image must appear in the ingredients list. It’s fine if its use is optional in the method (e.g. garnish).
- Do not list **salt**, **pepper** (or black pepper), or generic **oil** as ingredients—treat them as pantry staples. Keep them in the method where needed. Only list named oils when they’re specified (e.g. olive oil, sesame oil).

## Descriptions

- Make descriptions more appealing and appetising where they’re bland or matter-of-fact. Keep tone natural; avoid hype or flowery language.

## Preparation field

- Use the preparation field only when it’s a standard prep (e.g. “butterflied” for chicken). Don’t use prep terms that don’t apply (e.g. “butterflied” for pork).
- For meat that needs flattening or tenderising (e.g. pork for schnitzel), describe that in a method step, not in preparation. Leave preparation undefined when there’s no clear prep. Apply this rule consistently across all recipes.

## Cooking technique and quality

- Apply solid, home-cook-friendly technique so results are consistently good. Examples:
  - Tofu: squeeze out moisture before frying.
  - Beef/chicken: season before frying or searing.
  - Rice: include clear rice-cooking steps when rice is served. Same applies for pasta.
- Add method detail where it improves the dish (e.g. resting meat, when to add salt). Write as an expert chef who cares about these details.

## Pro tips for home cooks

- Weave in brief, practical tips where they help: deglazing the pan, searing at high heat, reducing stocks, seasoning in layers, resting proteins, balancing fat with acids etc. Aim for easy to follow but not dumbed down—meals should feel considered, not bland.
